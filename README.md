<h1 align="middle">TableOrder (테이블 오더)</h1>
<h3 align="middle">아주대학교 축제 주점 전용 실시간 주문 및 관리 시스템</h3>

<br/>

## 📝 작품소개
**TableOrder**는 아주대학교 축제 기간 중 운영되는 주점의 혼잡함을 해소하고, 주문 체계를 디지털화하기 위해 개발되었습니다. 고객은 테이블에서 QR 코드를 통해 즉시 메뉴를 확인하고 주문하며, 운영진은 관리자 대시보드를 통해 실시간으로 주문 접수, 조리 상태, 재고 현황을 파악할 수 있는 통합 솔루션입니다.

<br/>

## 🌁 프로젝트 배경
매년 수많은 인파가 몰리는 대학교 축제 주점에서는 종이 주문서 분실, 주문 누락, 현금/계좌이체 확인 지연 등 다양한 운영상 어려움이 발생합니다. 특히 피크 타임의 병목 현상은 매출 손실과 고객 불만으로 이어집니다. 

저희 팀은 이러한 문제를 해결하기 위해 **'주문부터 서빙까지의 전 과정을 자동화'**하는 것을 목표로 삼았습니다. 
- **정확성**: 수기 주문의 휴먼 에러를 0%로 차단
- **효율성**: 주문을 받기 위해 테이블을 오가는 불필요한 동선 제거
- **실시간성**: 주류 및 안주의 재고 소진 상황을 고객 앱에 즉각 반영

<br/>

## ⭐ 주요 기능
주점 운영의 A to Z를 고려한 핵심 기능들입니다.

- **[Customer] 테이블 주문 시스템 (React)**
    - 테이블별 고유 QR을 통한 간편 접속 및 주문
    - 실시간 품절 상태 반영 및 카테고리별 메뉴 탐색
    - 주문 내역 및 합산 금액 실시간 확인

- **[Admin] 통합 관리 대시보드 (Vue)**
    - 주문 접수 시 알림 및 주방 전용 주문 리스트 제공
    - 테이블별 점유 현황 및 매출 통계 대시보드
    - 메뉴 On/Off 기능을 통한 유연한 재고 관리

- **[System] 실시간 상태 동기화**
    - 주문-주방-관리자 간의 실시간 데이터 연동
    - 대량 주문 트래픽 처리를 위한 최적화된 API 설계

<br/>

## 🔧 Stack

**Frontend**
- **Language**: JavaScript (ES6+)
- **Frameworks**: **React** (고객용 모바일 웹), **Vue** (운영진용 관리 페이지)
- **Library**: Axios, Styled-Components (React), Vuex (Vue)

**Backend**
- **Language**: Java 11
- **Framework**: **Spring Boot / Spring MVC**
- **Database**: **MySQL**

**Infrastructure**
- **Cloud**: **Oracle Cloud Infrastructure (OCI)**
- **Deploy**: **CI/CD With Oracle**

<br/>

## 💡 기대효과
- **운영 비용 절감**: 주문 인력을 서빙 및 조리에 집중 배치하여 인건비 대비 효율 극대화
- **매출 증대**: 주문 속도 향상으로 테이블 회전율 약 20% 이상 개선 기대
- **데이터 기반 운영**: 축제 종료 후 판매 데이터를 분석하여 향후 주점 운영의 레퍼런스로 활용 가능

<br/>

## 👍 활용분야
- **대학 축제 및 행사**: 단기적으로 대량의 트래픽이 발생하는 팝업 스토어나 주점에 최적화
- **소규모 외식 사업장**: 고가의 테이블 오더 장비 도입이 부담스러운 소상공인을 위한 웹 기반 대안

<br/>

## 🔨 프로젝트 구조
전통적인 MVC 패턴을 기반으로 안정적인 데이터 처리와 직관적인 UI 관리에 집중했습니다.
